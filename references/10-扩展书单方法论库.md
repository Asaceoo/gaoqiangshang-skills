## 一、《沟通的方法》脱不花（得到 CEO）—— 中国语境职场沟通全流程手册

**核心认知**：沟通不是口才比赛，是「用最小成本让对方愿意跟你合作」；沟通是一场**无限游戏**——不是争对错，是让关系和合作延续。

### 结构化倾听：倾听三角形

对方每段话都含三层信息：**事实**（他说了什么）/ **情绪**（他此刻感受如何）/ **期待**（他希望我做什么）。

**反向叙述三步**（确认真听懂了）：
1. **响应情绪**：先点破情绪——「您先别着急」「我理解你现在挺委屈的」。路标词：**对方说「总是、老是、每次」时，说明在宣泄情绪**，先降情绪再谈事实。
2. **确认事实**：「您刚才说的是 X 情况，我理解得对吗？」
3. **明确行动**：「接下来我会在 X 时间内做 Y，可以吗？」

### 听话听音：四种沟通风格

| 类型 | 特征 | 害怕 | 有效沟通方式 |
|------|------|------|--------------|
| 老虎 | 控制型、目标导向 | 失控 | 直给结果、给选择题不给问答题 |
| 孔雀 | 取悦型、爱表现 | 被忽略 | 肯定他、给表现机会 |
| 猫头鹰 | 谨慎型、讲逻辑 | 混乱 | 给数据、给流程、别催表态 |
| 考拉 | 温和型、怕变化 | 非正常状态 | 主动维护、给安全感、变化前打预防针 |

### 三大沟通原则

1. **开放性 = 扩大共识 + 消除盲区**（乔哈里视窗）：多说「我们」少说「你我」；句尾留开放口——「我刚才说清楚了吗？」「你觉得呢？」
   - ❌「你这个月 OKR 进展怎么这么慢？」→ ✅「你看我做点什么能把咱们部门的 OKR 推进一下？」
2. **目标感 = 方案力**：句式「**我们有一个目标要达成，对此我有一个方案**」。「6 个月之后法」：用半年后的愿景倒推今天各自的调整。
3. **建设性 = 可执行的最小化行动 + 可持续的行动阶梯 + 每节点的即时反馈**：口头禅「来，我们抓抓落实」「请您再给我提点需求」「我能替你做点什么，帮你把这事办成」。

### 18 场景公式精选（每个都是「公式 + 原话」）

| 场景 | 公式 | 原话示例 |
|------|------|----------|
| 破冰 | 同校/同乡/同好 + 关切 + 后续互动 | 「咱们还是校友，你当时在哪个食堂吃？」 |
| 赞美 | 打追光：照亮行为而非禀赋，轻轻地+深深地+常常的 | 「你上次处理客诉的步骤我学走了」 |
| 接受赞美 | 谢谢 + 开放性结尾 | 「谢谢你发现了这一点，你最近那个项目怎么样了？」 |
| 激励 | 及时赞美 + 行为建模 + 反馈闭环 | 「你做得真好，**请问你是怎么做到的？**」（引导对方总结方法论） |
| 说服 | 强准备 + 吹风 + 慢熬；把目标变成对方目标的子集 | 「领导，我认真学了您会上讲的 X 目标，为落实它我做了方案，请您看看」 |
| 安慰 | 轻度介入 + 提供支持（不说「你应该」） | 「我会陪着你。需要我做点什么，随时说」 |
| 批评 | 控制环境 → 定义问题 → 刷新动作 → 设定反馈点 → 完成重启 | 「这块没做好。问题出在哪？你都试了什么？需要我做什么？」（最后一句话让对方说） |
| 提意见 | 事前征求同意 + 定义关系 + 具体建议 | 「我对这事有些建议，有兴趣听听吗？」 |
| 道歉 | 关闭过去（「你是对的」）+ 承诺未来（开新行动） | 「这事你是对的，是我考虑不周。以后这类事我提前跟你对齐」 |
| 调解 | 处理情绪 + 重建目标 + 最小改善 | 「你觉得他为人是好是坏，跟你当初的目标有关系吗？咱们先回到正轨上」 |
| 求助 | 别人帮得了 + 自己值得帮 + 真诚领情 | 「我试过 A 和 B 都不行，这个环节正好是你擅长的」 |
| 拒绝 | 开门见山（第一时间+第一人称+一个理由）+ 移花接木（替代方案） | 「这周我确实接不了。如果下周交付可以，我周一就排上」 |
| 即兴发言 | 万能开头（自黑或赞美一个现场细节）+ 谈感受/谈行动 | 「我今天就讲一个感受：刚才 X 说的那句对我冲击最大……」 |
| 闲谈 | 传递尊重（上个请教）+ 传递价值 | 「您是这方面专家，我正好想请教一个问题」 |
| 汇报提案 | 融目标 + 抢进度 + 提诉求 | 「这事按您的 X 目标推进的，已经做完第一步，需要您拍板一个小请求」 |
| 竞聘 | 肯定现有战场 + 我的独特打法 + 我的充分准备 | （不说前任坏话、不摆过去功劳、讲未来抓手） |
| 被拒绝后 | 不死缠，备次优方案 | 「没关系。那 A 方案先推进，这事我再想想别的路子」 |
| 拿回主动权 | 换口径 / 换时间 / 换场合 / 换角色 | 「这事比较重要，咱们明天上午专门开个短会聊，您看十点行吗？」 |

## 二、《谈话的力量》艾伦·加纳 —— 零基础对话技巧工具箱（100+ 实操）

**核心立场**：善于交谈不是天赋，是一组可习得的微技巧；冷场不是失败。

1. **开放式提问替代封闭式**：搭配比例「2 个封闭式 + 1 个开放式」防审问感。
   - ❌「工作顺利吗？」（只能答是/否）→ ✅「最近项目里让你最有成就感的部分是什么？」
2. **自由信息法**：抓住对方**随口透露的细节**延展话题，永远不愁没话说。
   - 「我周末爬山累坏了」→ 别只说「辛苦了」，抓住「爬山」：「你一般去哪座山？第一次走那条线吗？」
3. **高质量赞美公式**：**称呼 + 具体事实 + 赞美 + 追加提问**（用问题收尾，对方不用尴尬地接夸）。
   - 「小李，刚才开会你把复杂问题梳理得很清晰，你平时是怎么整理思路的？」
4. **接受夸奖**：大方说「谢谢」即可，**不必立刻反夸**，也不必贬低自己。
5. **「我-陈述」（I 陈述）**：吵架/提意见时用「我」开头代替「你」指责。
   - ❌「你总是很晚回家，根本不在乎我！」→ ✅「你到很晚才回来的时候，我一个人吃饭觉得很孤单。」
6. **破唱片法**：面对纠缠、道德绑架，**温和而坚定地重复同一句拒绝**，不辩论、不动摇。
   - 「你们预算宽裕，帮我们垫一下嘛」→「我理解你们急，但我垫不了。」「就这一次嘛」→「我知道，但我垫不了。」（同一句，语气不变）
7. **自我表露分级**：客套话 → 事实交换 → 意见交流 → 感受分享。过早深度表露让人不适，久留事实层关系难深化。
8. **积极倾听**：用语言反馈确认——「听起来你有点沮丧，是这样吗？」避免轻率下定义或安慰。

## 三、《被讨厌的勇气》岸见一郎/古贺史健 —— 阿德勒心理学：课题分离

**适用**：怕被否定、讨好型表达、人际内耗。

1. **课题分离**：判断「这是谁的课题」的唯一标准——**这个选择的后果最终由谁承担**。我只负责我的课题，不越界替对方做决定，也不让对方的课题绑架我。
   - 「我这么说话，他会怎么看我」——对方怎么看你，是**他的课题**。你能做的是真诚表达（你的课题）。
   - 话术应用：表达立场后不追问「你会不会不高兴？」——「这是我的想法，怎么决定在你。」
2. **目的论代替原因论**：不说「我嘴笨所以不敢说话」（原因论=宿命），而问「我不敢说话，是因为我『不出场』对现有目的更有利吗？」——行为服务于目的，目的可以改。
3. **横向关系**：不表扬也不批评（都是纵向操控），用**鼓励**——「谢谢你帮了我」「我很高兴」。
4. **共同体感觉**：把「这个人怎么看我」换成「我能给这个集体贡献什么」——沟通焦虑立减。

## 四、《亲密关系》罗兰·米勒（豆瓣 9.3）—— 人际关系的科学研究

> ⚠️ **同名不同书，引用前务必确认作者**：中文书名叫《亲密关系》的**至少有两本**——
> ① **罗兰·米勒**（Rowland Miller）*Intimate Relationships*，**大学教材**、实证研究综述（**本库引用的是这本**）；
> ② **克里斯多福·孟**（Christopher Moon），张德芬译，**灵修/自助**向，讲"伴侣是灵魂的镜子"。
> 两者**结论常有冲突**（一个讲研究结论，一个讲灵性成长）。微信读书「心理学相关」书单收录的是**孟版**。
> 说"《亲密关系》指出…"时**必须带作者名**。详见 `15-资源地图与源可信度评级.md` §八 发现 2。

1. **自我表露互惠律**：关系深化靠「渐进而相互的自我表露」——你透露一点真实的自己，对方回报一点，螺旋上升。僵局解法：你先走一步（适度先行表露）。
2. **要求/回避（Demand/Withdraw）模式**：一方施压提要求、一方回避沉默——**最危险的沟通循环**。解法：回避方先开口承诺一个具体讨论时间（「我需要点时间，今晚九点咱们认真聊，行吗？」），施压方在此期间不追问。
3. **验证式沟通**：冲突中先承认对方观点有合理性再说己方——「我明白你为什么生气，这事换我也会有情绪。同时我想说……」。与之相对的是「否认/攻击/忽视」。
4. **幽默与关爱的修复力**：带善意的玩笑、身体接触、一句「我爱你但我不喜欢这件事」比讲道理更能降火。

## 五、《社会心理学》戴维·迈尔斯（豆瓣 9.4）—— 沟通背后的心理机制

1. **自我应验预言**：你如何看待自己 → 影响你的表现 → 强化他人对你的方式 → 回流强化自我设定。话术应用：多用**正向预期表达**——「我知道你肯定能安排好」（预期影响行为），少说「你可别又搞砸」。
2. **基本归因错误**：评价他人行为时高估性格、低估情境；评价自己时相反。沟通应用：对方迟到，先想「他可能堵车」（情境归因）再想「他不尊重我」（性格归因）——开口前先自问。
3. **登门槛效应**：先小请求后大请求，承诺升级——与《影响力》承诺一致互证。
4. **过度合理化效应**：外部奖励会稀释内在动机——夸孩子画画的「用心」而非每画必给物质奖励。同理：赞美行为过程，不绑定交易。

## 六、《也许你该找个人聊聊》洛莉·戈特利布 —— 倾听与回应的 therapist 视角

1. **不急着「解决问题」**：对方倾诉时，先陪他停在感受里——「这确实太难了」，而不是立刻「你可以试试 X」。
2. **「和自己的对话」也值得检查**：你对自己说话的方式（「我真没用」）往往比对别人凶——自我慈悲句式：「换我最好的朋友遇到这事，我会对他说什么？」
3. **故事的改写**：同一个事实可以讲成「受害者版」也可以讲成「行动者版」——倾诉完补一句「这里面你做的哪一步，是你后来觉得还不错的？」帮对方（和自己）换版本。

## 七、《演讲的力量》克里斯·安德森（TED 掌门人）—— 当众表达

1. **主线原则**：一次演讲只传递**一个核心思想**——「今天我只讲一件事……」比面面俱到有力十倍。
2. **故事 + 惊讶 + 幽默**：开头 30 秒用故事或意外事实抓住注意力；数据要「人格化」（「这个数字相当于每 30 秒一架客机坠落」）。
3. **真诚是技术的前提**：分享真正的热情与教训，观众对「表演感」极其敏感——与本技能铁律「真诚优先」互证。

## 八、《社交天性》马修·利伯曼 —— 社会脑的三次适应（简深）

1. **「社会疼痛」是真实的疼痛**：被排斥、被当众否定，大脑激活的区域与生理疼痛重叠——**当众社死的痛不是矫情**。话术应用：永远别当众否定人；自己被当众否定，允许自己「疼」，先离场缓冲再回应。
2. **连接先于理解**：大脑天生先做「连接判断」（敌友？）再做「理性分析」——所以先修复关系温度，再讨论事实（与关键对话「安全感先行」互证）。
