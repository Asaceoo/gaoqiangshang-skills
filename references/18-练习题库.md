# 18-练习题库

> **教练模式 · 出题专用库**（v1.42.0 新增）。触发词：「出练习题」「考考我」「练练我」「来几道题」。
> 使用规则：AI 从本库**按场景抽题**→用户作答→AI 按五维评分（语气温度/环境场合/方式分寸/逻辑事实/目标边界）→给出参考答案（引自对应话术库）→可「再来一题」连续训练。

## §B 训练模式说明

### B1 难度分级

| 级别 | 适用 | 抽题规则 |
|------|------|---------|
| ⭐ 入门 | 新用户 | A1/A2/A3 基础场景，直接给参考答案对照 |
| ⭐⭐ 进阶 | 熟练用户 | A4-A8，AI 先评分再给参考 |
| ⭐⭐⭐ 实战 | 高阶用户 | A9/A10，AI 扮演对方 role-play，压力测试 |

### B2 评分维度（五维自检表同源）

1. **语气温度**——有没有让对方舒服？
2. **环境场合**——公开/私下、亲疏匹配？
3. **方式分寸**——表达方式是否恰当？
4. **逻辑事实**——有没有事实错误或逻辑漏洞？
5. **目标边界**——是否达成目标且不越界？

### B3 抽题算法

- 用户说「来一题」→ 随机抽 1 题（跨类均匀）
- 用户说「来道拒绝的题」→ 定向 A4 抽
- 用户说「专练拒绝/安慰/说服…」→ **§A2 对应 S 组定向抽题**（专项深化）
- 用户说「难一点的」→ 升难度级别
- 用户答完 → 五维点评 → 参考答案 → 「再来一题？/ 换个场景？/ 出道难的？」
- 抽题顺序建议：⭐ 从 §A 抽 → ⭐⭐ 从 §A2 抽 → ⭐⭐⭐ 从 S10/标注实战题抽
