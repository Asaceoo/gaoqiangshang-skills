# 18-练习题库

> **教练模式 · 出题专用库**（v1.42.0 新增）。触发词：「出练习题」「考考我」「练练我」「来几道题」。
> 使用规则：AI 从本库**按场景抽题**→用户作答→AI 按五维评分（语气温度/环境场合/方式分寸/逻辑事实/目标边界）→给出参考答案（引自对应话术库）→可「再来一题」连续训练。

## §B 训练模式说明

### B1 难度分级

| 级别 | 适用 | 抽题规则 |
|------|------|---------|
| ⭐ 入门 | 新用户 | §A 基础题 + §D 判断题，直接给参考答案对照 |
| ⭐⭐ 进阶 | 熟练用户 | §A2 专项题，AI 先评分再给参考 |
| ⭐⭐⭐ 实战 | 高阶用户 | §E 多轮 role-play，AI 扮演对方实时变化态度，压力测试 |

### B2 评分维度（五维自检表同源）

1. **语气温度**——有没有让对方舒服？
2. **环境场合**——公开/私下、亲疏匹配？
3. **方式分寸**——表达方式是否恰当？
4. **逻辑事实**——有没有事实错误或逻辑漏洞？
5. **目标边界**——是否达成目标且不越界？

§E 多轮题额外考察：**目标达成度**与**跨轮一致性**。

### B3 抽题算法

- 「来一题」→ §A 随机
- 「专练 XX」→ §A2 对应 S 组定向抽
- 「实战演练」→ §E 多轮 role-play（⭐⭐⭐）
- 答完 → 五维点评 → 参考答案 → 继续邀请
- 顺序建议：⭐ §A/§D → ⭐⭐ §A2 → ⭐⭐⭐ §E
