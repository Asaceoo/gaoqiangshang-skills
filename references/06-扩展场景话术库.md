# 扩展场景话术库（v1.2 新增）

覆盖客户/甲方、跨部门冲突、公开即兴发言、真诚道歉、离职与谈薪收尾、微信文字沟通规范、长对话谈判策略。核心逻辑：**利益场景先找共同目的，文字场景先管语气和长度，收尾场景先定事实再谈感情。**

## 一、客户 / 甲方沟通

- **需求反复改**：不接情绪、锚定范围。"改没问题，咱们一起把这次的改动点定下来：这是新增需求，还是原方案内的优化？新增的部分我同步评估下排期，避免互相误伤预期。"
- **甲方压价**：用增值替代让步 + 给选择题。"直接降价会影响服务投入。我建议两个方向：A 维持预算，增加 X 服务；B 缩减范围到核心模块，价格降到您的预期。您更看重哪边？"
- **客户发火**：先降温再处理。"您先消消气，这个问题我现在记下来了，半小时内给您一个处理方案和时间表。"（先给时限承诺，稳住情绪，再给方案）
- **对外口径**：不当众背锅也不当众甩锅。"这个环节我们在内部先复盘，对外口径今天下班前统一给您。"

## 二、跨部门冲突 / 推诿

- **对方不配合**：把"你要做"变"我们要"。"这事卡住的话咱俩都得向上交代。我先出个协作清单，把双方要做的列清楚，你看哪条有困难我们调。"
- **群里/邮件冲突**：公开场合只对事、留证据、不定性。"关于 X 环节的阻塞点，我理解是 A 资源未到位（事实）。建议今天拉个 15 分钟会对齐优先级（方案）。"
- **被甩锅**：不当众自证，私下摆事实。"关于昨天会上提到的延误，我补充下时间线：X 日我提交了 Y，Z 日收到反馈……明细发您邮箱，咱们对一下，看卡在哪一环。"
- **需要领导介入**：抬决策者但不树敌。"这个涉及两个部门的优先级，您看是否需要请王总拍个板？我们把方案先准备好。"

## 三、公开即兴发言（PREP + 结论先行）

- **公式**：观点（Point）→ 理由（Reason）→ 例子（Example）→ 重申观点（Point），时长 30 秒~1 分钟为宜。
- **被突然点名**："感谢主持人。我的观点是……，理由有两点：一……二……。举个身边的例子……。所以总的来说，我支持/建议……"
- **没有观点时**：借力起头，不硬憋。"前面的分享我都很受启发，我补充一个大家可能用得上的视角……"
- **说完冷场**：主动收尾交还话筒："我就先说这些，看看大家有什么补充？"

## 四、真诚道歉（不是"对不起"三个字能解决）

**四步：认领具体错误 → 不辩解 → 说补救 → 请求反馈。**

- 职场："这次延期是我的责任——我在 X 环节低估了工期，没有提前预警。不找借口。补救方案是……今天内完成。您看这样处理可以吗？"
- 私人："那天我说那句话伤到你了，是我的问题。我想……（补救动作）。你能告诉我，你现在最需要我做什么吗？"
- ❌ 雷区："但是你也……"（道歉里带转折 = 翻案）；"我都道歉了你还想怎样"（情绪勒索）；"好好好都是我的错"（敷衍式认错）。

## 五、离职 / 谈薪收尾

- **提离职**：先感恩 + 定事实，不谈对错。"这段经历我学到很多。经过慎重考虑，我决定……。交接我会做完整清单，保证平稳过渡。"
- **被挽留加薪**：不当场答应也不当场拒绝。"很感谢公司认可，我需要两天时间认真考虑，周四前给您答复。"（给自己留思考空间）
- **谈薪被拒的收尾**：把"不"变成"条件"。"理解公司目前的考虑。我想请您明确一下：达到什么标准/时间点可以重新评估？我们把它定下来。"
- **离职原因被追问**：只说向前看，不说向后怨。"不是公司不好，是我自己的方向想调整，这个决定跟谁都没关系。"

## 六、微信 / 文字沟通规范

- **长度**：一条消息不超过 5 行；要讨论超过 3 个问题就约电话或见面，别在文字里连环轰炸。
- **语气**：少用"？？"连发和"哦""呵呵"；语气词和表情可以软化语气，但工作场合每条不超过 1 个。
- **时间**：非紧急消息避开深夜和早晨 8 点前；紧急事项直接打电话，不要只发文字等回复。
- **开场**：不说"在吗"，直接说事 + 给成本预估："有个 X 的事想请你帮个忙，大概需要 10 分钟，方便时回我。"
- **已读不回**：隔天换个角度重发一次（补充新信息："补充个情况……"），不质问"怎么不回我"。
- **撤回与改口**：发错消息大方认："手滑发错了，重新说——"比假装无事发生更体面。

## 七、长对话谈判策略（多轮）

- **开局定调**：先说共同目的（关键对话式开场）："咱们目标是一致的，都是想把这事做成。"
- **中局让步**：每次让步都要换条件（"价格可以谈，交期要放宽一周"），**不单方面让**；让步幅度递减，传递"接近底线"的信号。
- **僵局处理**：拆分议题 + 明确回复时限。"这块咱们先放一放，把能定的先定下来。卡点我回去再想办法，周四前给您回复。"
- **收尾**：口头共识当场复述确认："我们确认下：A 这样、B 这样，我今天整理成文字发你。"（防事后扯皮，也显专业）
