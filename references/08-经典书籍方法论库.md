## 一、《掌控谈话》克里斯·沃斯（FBI 首席人质谈判专家）—— 战术同理心六步

**适用**：对方进入防御/情绪激烈/谈判僵持。核心理念：**谈判本质是情绪问题，不是理性问题**——让对方"被理解"比"被说服"更有效；战术同理心 ≠ 认同对方，是深刻理解对方立场的同时坚定持有己方立场。

### 六步流程

1. **积极倾听姿态**：「嗯」「我懂」「然后呢」——不是敷衍，是"我在听"的信号，降低对方防卫。
2. **镜映（Mirroring）**：重复对方**最后 1~3 个词**（升调），然后沉默 4 秒。人在被重复时感到被理解，会自动展开解释——用三个字换三分钟情报。
   - 对方：「这个方案风险太高了。」→ 你：「风险太高了？」（沉默）→ 对方自动说出具体担心什么。
3. **标注情绪（Labeling）**：用「**听起来**…」「**看起来**…」开头（**不用「我」**，焦点留在对方身上），把对方情绪说出来。神经科学依据：情绪被语言命名后强度下降。
   - 客户发火：「我已经等了 20 分钟，这是第三次解释问题！」→「听起来您对这个流程非常恼火。」→「对！我就是想把事情解决掉。」（怒气消退，开始合作）
4. **策略性沉默**：标注完停顿，不急推进。对方会在沉默中补充或修正你的标注（「不是压力，是我觉得不被尊重」——更精确的情报）。
5. **校准问题（Calibrated Questions）**：以 **How/What** 开头的开放式问题把解题球抛给对方，**禁用 Why**（触发防御）。精髓：让对方亲手设计他自己能接受的方案。
   - 不说「这个价格我做不了」，说「我要怎么做才能做到这个价格？」
6. **引导承诺**：让对方用自己的话说出你想要的结论——「所以如果时程延长两周、预算加 15%，您就能全力推进？」承诺一致性让他很难反悔。

### 标注情绪句库

| 情绪 | 标注句 |
|------|--------|
| 怒 | 「听起来您对 ___ 很生气。」 |
| 怕 | 「好像您担心 ___ 会发生。」 |
| 挫败 | 「这件事让您很挫败。」 |
| 不公 | 「您觉得这样不公平。」 |
| 压力 | 「听起来这个时程让您压力很大。」 |

### 校准问题场景表

| 场景 | 校准问题 |
|------|----------|
| 加薪 | 「什么数据能帮您把这事批下来？」 |
| 谈薪/砍价 | 「我要怎么做才显得公平？」 |
| 排期冲突 | 「什么条件能让这个时程可行？」 |
| 分工 | 「怎样安排对您的团队最可行？」 |
| 推进合作 | 「什么阻止我们达成一致？」 |
| 被甩锅 | 重复对方最后几字：「怪…我？」（沉默 4 秒）——多数人会心虚改口 |

### 三个补充要点

- **指控审计（Accusation Audit）**：开会前先把对方可能想到的指责说出来——「您可能会觉得我太难缠……」——负面预期被提前拆掉。
- **「你说得对（That's right）」才是真同意**；「你是对的（You're right）」是敷衍逐客令。追求前者。
- **「没有」是谈判的开始不是结束**：对方说「不行」时镜像它——「不行？」——真正的顾虑会跟出来。

### 反模式

| 误用 | 后果 | 纠正 |
|------|------|------|
| 标注带讽刺语气 | 更炸 | 真诚、平缓 |
| 只倾听不让步 | 被当软柿子 | 倾听后清晰说出己方主张 |
| 镜像后立刻反驳 | 白听 | 先听两轮再推进 |
| 无底线倾听 | 被榨干 | 见好就收，适时给具体方案 |

## 二、《高难度谈话》道格拉斯·斯通（哈佛谈判项目组）—— 三层对话模型

**适用**：谈崩的根源不是话术，是三层对话错位。任何艰难对话其实同时进行着三场对话，**只处理第一层必然翻车**。

| 层 | 表面问题 | 陷阱 | 正确转向 |
|----|----------|------|----------|
| ① 发生了什么 | 争谁对谁错 | 「真相陷阱」：把己方版本当事实 | 停止争对错 → 换成**视角交换**；从「谁的错」转向**「双方各贡献了什么」（贡献系统）**——注意：贡献 ≠ 过错 |
| ② 情绪 | 假装情绪不存在 | 情绪以「翻旧账、阴阳怪气」泄漏出来 | 先承认情绪再谈事实：「我对这件事有情绪，先说出来免得影响后面」 |
| ③ 自我认知 | 「这件事说明了我是怎样的人」 | 身份动摇（我称职吗/是好人吗/被尊重吗）导致过激反应 | 识破复杂化：「一次失败 ≠ 无能的人」 |

**关键话术转向**：
- 「你太自私了」→「我觉得这个安排对我的付出考虑得不够，想和你聊聊我的感受。」（指责 → 感受+影响）
- 「不是我的错」→「我们各退一步梳理：哪些环节是我可以做得更好的，哪些是你那边的信息我没掌握的。」（对错 → 贡献系统）
- 意图 ≠ 影响：对方迟到让你生气是**影响**，但他可能不是**故意**——「我不是说你故意，但这件事对我的影响是……」

## 三、戈特曼研究所《幸福的婚姻》—— 修复尝试与四骑士

**适用**：亲密关系冲突。约翰·戈特曼对数千对夫妻 40 年实证研究：**幸福的夫妻不是不吵架，而是会修复**；修复尝试的成功率直接预测关系走向。

### 四骑士与解毒剂

| 骑士 | 表现 | 解毒剂 |
|------|------|--------|
| 批评 | 「你**总是**」「你**从来**」（攻击人格） | 软化启动：用「我」开头，描述事实+感受（见下） |
| 防御 | 反击、推责、装受害者 | 承担哪怕 2% 的责任：「这部分确实是我没做好」 |
| 蔑视 | 讽刺、翻白眼、贬低（**最强离婚预测指标**） | 建立欣赏文化：日常主动说出对方的具体优点 |
| 筑墙 | 冷战、已读不回、转身就走 | 生理自救暂停 20 分钟再回来（心血管被淹没时无法沟通） |

### 修复尝试句库（吵架中随时可用，摘自戈特曼官网）

- **表达感受类**：「我有点害怕了」「请说得温和一点」「我感觉你没在听我说」
- **喊停类**：「我需要冷静一下，20 分钟后回来继续，好吗」「能不能先换个话题缓一缓」
- **认错类**：「让我重新说一遍刚才的话」「对不起，我搞砸了，我确实有做得不对的地方」「我想温柔地说，但我不知道怎么开口」
- **肯定类**：「这不全是你的错」「谢谢你听我说这些」「我知道你现在也很难受」

### 软化启动公式

对话通常以同样的基调结束——**开头软，结尾才软**。

公式：**「我感到 + 情绪」+「关于 + 具体事实」+「我需要 + 正面请求」**

- ❌「你眼里根本没有这个家！」
- ✅「我最近觉得有点孤单（情绪），这周你有三天应酬到很晚（事实）。周末能不能留半天给我们俩（请求）？」

### 另外两条

- **接受影响**：让对方知道「你的意见我有认真考虑」——「你这个想法有道理，我采纳一半。」
- **永久性问题**：夫妻 69% 的矛盾是永久性的（性格差异）——目标不是解决，是**对话**；僵局背后藏着没说出口的梦想（「我坚持孩子要上重点，因为我怕他吃我吃过的亏」）。

## 四、《爱的五种语言》盖瑞·查普曼 —— 先对频再表达

**适用**：明明付出了对方却感受不到。五种种爱的语言：**肯定的言语 / 优质的陪伴 / 服务的行动 / 身体的接触 / 精心的礼物**。

- 每个人的「主爱语」不同：你拼命送礼物（己方爱语），对方要的是陪伴（对方爱语）——**用错了频道，努力打折**。
- 操作：① 回想对方最常抱怨什么（抱怨「你不陪我」→ 主爱语是陪伴）② 回想对方最常主动做什么（他总帮你做事 → 他的爱语是服务行动）③ 按**对方**的主爱语表达。
- 配套句子：「你上次说的那句肯定的话，我记到今天」「这周末手机放一边，我陪你一整天」。

## 五、《影响力》罗伯特·西奥迪尼 —— 六武器的正向使用

| 武器 | 正向用法 | 话术例 |
|------|----------|--------|
| 互惠 | 先给小帮助/小让步 | 「这个方案我先帮你改了一版初稿，你看看」 |
| 承诺一致 | 引导小承诺再升级 | 「先试运营一周，觉得好我们再签全年」 |
| 社会认同 | 用同类人行为佐证 | 「你同桌每天多做 3 道题」（对孩子）/「同批项目都用这个方案」 |
| 喜好 | 真诚具体地赞美 + 找共同点 | 「你上次处理客诉的方式我特别服」 |
| 权威 | 引用专业标准/数据背书 | 「按行业通行标准，这个比例是……」 |
| 稀缺 | 说明客观窗口期 | 「这个价只到本月底，过了要重新审批」 |

> 红线：六武器只用于**真实信息**的更有效表达；虚构社会认同或假稀缺 = 操控，触发技能铁律拒绝。

## 六、《哈佛谈判课（Getting to Yes）》—— 利益、立场与客观标准

**适用**：谈条件、分资源、商务谈判。

- **立场 vs 利益**：立场是「我要 8000」，利益是「我要覆盖搬家成本且下月房租不愁」。围绕利益谈，选项立刻变多（分期、补贴、报销）。
- **客观标准**：情绪升温时把讨论拉回外部标尺——「咱们别拍脑袋，看看市场价/合同第几条/行业惯例。」
- **BATNA（最佳替代方案）**：进谈判前想清楚「谈不成我有什么退路」——有 BATNA 的人语气自然稳。
- **把饼做大**：先一起扩展选项菜单再谈分配——「除了加薪，弹性工时/培训预算/晋升节点，哪些对你也有价值？」

## 七、《高效演讲》—— 坡道-发现-甜点（当众发言结构）

- **坡道**：开头 7 秒用「与听众有关的问题/故事」抓住注意力，不说「我今天汇报三部分」。
- **发现**：中间给 3 个要点，每点配一个故事或数据。
- **甜点**：结尾回到情感与行动号召，不以「谢谢大家，Q&A」仓促收场——先给一句升华，再谢幕。

## 八、《情商》戈尔曼 + 《共情的力量》—— 情绪能力的四步

1. **自我觉察**：情绪升起时先命名它（「我现在是挫败，不是愤怒」）——命名即降温。
2. **暂停**：生理唤醒时（心跳加快、脸热）不说话——**约 90 秒**。
   - **出处更正（v1.39.4）**：「90 秒规则」出自**吉尔·博尔特·泰勒**（Jill Bolte Taylor，神经解剖学家）*My Stroke of Insight*（2008，中译《奇妙的脑》）；**戈尔曼**的概念是「杏仁核劫持」（amygdala hijack），**并未提出 90 秒数字**——此前归属有误。
   - **严谨提示**：90 秒是**经验法则**（生理唤醒的自然消退量级），**不是精确测量值**——实际消退时长因人因事而异，引用时说「通常一分钟上下」比「精确 90 秒」稳妥。
3. **共情镜映**：复述对方的情绪并确认——「你听起来挺委屈的，是吗？」——**先处理心情，再处理事情**。
4. **回应而非反应**：反应是本能（怼回去），回应是选择（「你想说的是不是……」）。

## 九、《关键冲突》—— 先判断该谈哪一层

冲突发生时问自己：这该谈**内容**（这次做错了什么）/ **模式**（反复发生）/ **关系**（信任与承诺）的哪一层？

- 第一次出错 → 只谈内容（「这份报表有 3 处数据错了」）
- 同样问题第二次 → 谈模式（「上次也出现同样的情况，我们聊聊怎么避免」）
- 你开始不想信对方 → 谈关系（「最近几次交接我都有点忐忑，想和你聊聊我们怎么互相放心」）

**误判层级的代价**：反复出错却只谈内容 → 你憋屈；第一次出错就上纲上线谈关系 → 对方委屈。

## 十、《非暴力沟通》倾听篇 —— 对方在愤怒时

01 库收录了 NVC 的表达四步，本节是**反向**：对方对你用情绪时，NVC 的倾听四步。

1. **不辩解、不纠正、不着急给建议**——对方要的首先是「被听见」。
2. **反馈观察**：「你觉得这周三次会议我都没听你说完，是吗？」
3. **猜测感受与需要**：「你是不是觉得不被尊重？你希望重要的事先和你商量？」——猜错没关系，对方会纠正你，纠正就是更精确的情报。
4. **确认后再表达自己**：「谢谢你告诉我。我解释一下我的情况，然后我们想想怎么避免，好吗？」

> 组合拳：对方愤怒 → 本库十（NVC 倾听）接住 → 转本库一（标注+校准问题）化解 → 需要谈条件转六（哈佛谈判）。
