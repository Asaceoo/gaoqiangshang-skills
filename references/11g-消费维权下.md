# 11g-消费维权下（11库拆分·§51-59）

> **来源**：11库拆分子文件，覆盖殡葬/早教/保健品/留学中介/理财骗局/招聘中介/陪诊/裁员赔偿等场景。

## 五十一、殡葬服务与家属沟通·礼仪策划避坑指南 ⏳

> 核心矛盾：家属在极端情绪状态下决策，销售侧最容易在信息不对称时高价推单。核心方法论：**流程闭环 + 报价透明 + 情绪缓冲 + 资质核查 + 全程书面化**。参考：mygov.tw 殡葬服务行业指引、ypsfw.com 五大核心要点、sina.cn 三个沟通技巧、香港仔日记避坑指南。

### 51.1 五大核心要点识别【ypsfw.com】

咨询阶段决定 90% 的后续纠纷，家属必须按五点核对：

| # | 要点 | 关键动作 | 常见坑 |
|---|---|---|---|
| 1 | 服务流程完整性 | 遗体接运→冷藏保鲜→遗容整理→告别仪式→火化→骨灰安放→后续祭扫**全流程闭环** | 只有中间几段，头尾外包 |
| 2 | 价格体系透明 | 价目表公开公示、明细到每一项（火化费/告别厅/骨灰盒单价） | 低价套餐诱导 + 后期按天加收冷藏费 |
| 3 | 个性化需求 | 支持简约追思/生态安葬（树葬/海葬/花坛葬）/宗教仪式 | 强制套餐、不允许自带物件 |
| 4 | 人员专业与共情 | 持证化妆师/遗体接运员/司仪 + **理解家属悲痛** | 冷漠流程化、为赶时间催促 |
| 5 | 机构资质信誉 | 民政部门《殡葬服务许可证》+ 营业执照 + 行业协会会员 | 临时挂靠的"黑中介" |

**核对话术**："麻烦您把流程分成『必选』『可选』『按天/按项加价』三类给我列个清单——冷藏一天多少、告别厅延时多少、法事是否另计？"

### 51.2 三个沟通技巧守住费用底线【sina.cn】

家属在悲痛状态下的三个高杠杆沟通动作：

1. **对比方案再提问**（用 A/B 方案暴露价格差异）：
   > "如果告别厅换成更安静的小厅，价格差多少？鲜花能否用当季本地花材替代？"
2. **把握情感表达权**（把"仪式感"从销售手里拿回来）：
   > "我们希望仪式能体现家人亲手布置的痕迹——播放自制相册视频，可以由家属操作吗？"
3. **书面化一切口头承诺**（把话术从口头搬到合同备注）：
   > "麻烦您在合同备注里写一下刚才说的鲜花更换方案。"

**警戒话术三词**（销售一出口立即警觉）：
- "**限时优惠**" → 拖延，明早再决定
- "**套餐更划算**" → 拆到单项核对单价
- "**今天定就便宜**" → 索要零增项承诺书

### 51.3 签约四必查【sina.cn + 香港仔日记】

合同签订阶段四个必查项 + 对应话术：

| 核对项 | 家属话术 | 作用 |
|---|---|---|
| 费用明细 | "合同里的总价，是否包含刚才说到的所有项目？会不会有临时加收？" | 确认"一口价"范围 |
| 服务时间 | "告别仪式几点到几点？延时怎么算？" | 明确时间边界 |
| 联络渠道 | "之后如需调整细节，我直接联系您个人可以吗？" | 建立一对一联络人 |
| 口头备注 | "麻烦把刚才说的方案写进合同备注" | 白纸黑字化 |

**关键三问**（初次咨询时主动提出，快速筛掉不专业机构）：
1. 是否有政府核准的**定型化契约 + 报价明细**？（正规业者会主动提供）
2. 整个治丧期间是否有**单一窗口全程陪伴**？（避免不同环节外包断链）
3. 遇到突发状况或调整流程，**弹性空间有多大**？（家属意见需要时间整合）

### 51.4 家属情绪与仪式规划五步【onestar.com.tw】

事先预谈 vs 事中慌乱——预谈能避免 80% 的临时加项：

1. **提前与长辈沟通意愿**：宗教信仰（佛/道/无宗教）+ 偏好（从简/隆重/追思）
2. **筛选参与亲友人数**：影响是否需租礼厅 + 服务人员配置
3. **设想仪式细节**：灵堂布置、纪念物品、音乐、回忆照片（可与礼仪公司预先讨论）
4. **规划预算三段**：丧礼花费 + 公私立设施租借 + 塔位牌位购买
5. **挑选礼仪公司**：书面合约 + 价格透明 + 客制化 + 团队经验 + Google/在地评价（**至少对比 2-3 家**）

**预谈对家属的心理价值**：谈身后事不是"忌讳"，是"让父母被尊重、让子女更安心"——把这段对话本身视为对父母的最终体面。

**核心方法论**：透明公开 + 尊重意愿 → 家属在有限预算内拿到圆满告别的最佳解。


## 五十二、儿童早教消费·试听推销与退费博弈 ⏳

> 核心矛盾：家长被"起跑线""敏感期"焦虑驱动，销售用话术放大焦虑促成大额预付。核心方法论：**试听四看 + 报价拆单 + 合同退费五查 + 大额必留证**。参考：renrendoc 早教销售技巧库、zhoube.com 招生话术、first-priority 培训机构高效沟通、m.sanlianzhaosheng.com 早教园招生问答。

### 52.1 销售套路五识【renrendoc + m.sanlianzhaosheng.com】

早教/儿童培训的五大经典推销套路识别：

| 套路 | 触发句式 | 反制动作 |
|---|---|---|
| 焦虑营销 | "3 岁前是黄金期""错过就晚了""孩子输在起跑线" | "我们不追求抢跑，只求陪伴孩子正常发育" |
| 假专家 + 义诊 | 穿白大褂的"老教授"免费测发育 | "能否提供这位专家的执业证编号？" |
| 温情牌 | 天天上门陪聊天/做家务，叫"叔叔阿姨"比亲还亲 | 拉女儿/家人旁观其"关怀"的连续性 |
| 夸大疗效 | "包治百病""根治三高""一个月见效"（儿童版："一个月开口讲话"） | 引《广告法》禁止绝对化用语，索要合规宣称 |
| 限时逼单 | "今天最后一天""仅剩 2 个名额""买三送三" | "先给书面报价单，我今晚回家和孩子爸商量" |

**观察式识别话术**（家长现场用，把话头拉回客观）：
- 销售说"每个孩子都不一样" → 反问"那您能否给我 3 个同月龄孩子的进步数据？"
- 销售说"孩子喜欢这个老师" → 反问"孩子是否也愿意和别的老师合作？我们可以做双向匹配"

### 52.2 家长异议应对反制（销售话术反向拆解）【m.sanlianzhaosheng.com + zhoube.com】

销售常用 5 类应对话术的破解：

**「价格太贵」** → 销售答："价格是总部统一规定，动不了。" → 家长破解：
> "总价可以不变，但请把单价、课时数、每节课时长、老师学历、教具清单拆开给我——我要看每一项是否合理。"

**「孩子不喜欢老师」** → 销售答："我们双向匹配。" → 家长破解：
> "匹配机制请写进合同：孩子不喜欢哪位老师可无条件换，且**换老师不额外收费**。"

**「再考虑考虑」** → 销售答："名额有限，招满就开课。" → 家长破解：
> "先给我一张『意向保留单』，7 天内有效；如果 7 天内名额被其他家长占走，请书面确认——这样我决策就有底。"

**「今天定就便宜」** → 销售答："限时优惠。" → 家长破解：
> "限时请写进报价单的日期，超过这个日期请给我**同等折扣的回溯条款**——不写进合同的不算。"

**「爷爷奶奶不同意」** → 销售答："老人不懂早教。" → 家长破解：
> "请把老人的担忧记录下来作为合同附件——如果老人反对点涉及课程内容，请在方案里逐项回应。"

### 52.3 试听四看 + 报价拆单【first-priority.com.cn】

试听是决策关键节点，家长用四看判断机构真实水平：

**试听四看**：
1. **看板书设计**：老师是否每节课留 10 分钟让孩子上台讲解（内向孩子三个月后能否主动举手）
2. **看具体观察**：销售能否说出"孩子在小组讨论时特别积极，但做题时急躁"这种**事实性分析**（比空泛夸赞专业）
3. **看反馈机制**：能否提供每周两次的课后反馈 + 阶段性成长档案（视频对比）
4. **看风险降低**：能否提供 1 个月体验课 + "有效果再续报长期班"的分阶段方案

**报价拆单五要素**（要求销售逐项列明）：
1. 单价 / 课时数 / 每节课时长（避免"20 课时"其实是 20×40 分钟）
2. 老师学历 + 证书编号（TESOL/蒙氏认证 等）
3. 教具清单（哪些包含、哪些另购）
4. 场地 + 停车 + 接送（是否包接送）
5. 退费条款（详见 52.4）

### 52.4 退费合同五查【renrendoc + 教培合同通用】

合同必查五项，任一项含糊都需重新起草：

| # | 查什么 | 常见坑 | 正确条款 |
|---|---|---|---|
| 1 | 退费触发条件 | 只有"不可抗力"才能退 | "孩子因故连续缺课 8 周以上可退" |
| 2 | 退费计算方式 | "已上课时的 100%" | "已上课时 90% + 未上课时 100% - 手续费 5%" |
| 3 | 退费时限 | "30 个工作日内到账" | "15 个工作日内全额到账，逾期按日万分之五罚息" |
| 4 | 手续费 | 30-50% | ≤ 5%，且**上限 500 元** |
| 5 | 换老师/换场地 | 无 | "换老师/换场地不影响退费计算" |

**合同必写**（家长主动要求销售备注）：
- "本课程不含隐性收费（教材费/活动费/保险费另计须事先告知）"
- "退费流程走银行转账，不接受现金"
- "机构关闭或转让时，未消课时按比例退还至家长"

### 52.5 维权阶梯 + 大额必留证

家长维权四级阶梯：

1. **协商**（1-7 天）：拿合同 + 报价单 + 转账记录要求退款，留书面沟通
2. **12315 投诉**（7-15 天）：市场监管热线，提交合同 + 证据
3. **教育局投诉**（15-30 天）：涉及教育资质问题
4. **诉讼退一赔三**（30 天+）：引《消费者权益保护法》55 条，虚假宣传欺诈 → 三倍赔偿

**大额必留证**（≥ 5000 元必须做）：
- 全程录音录像（合同宣读 + 试听）
- 销售话术聊天截图（微信记录）
- 转账记录 + 收据发票
- 机构资质（营业执照 + 办学许可证）拍照
- 3 天内把以上资料整理成 5 份电子档案（云端备份）


## 五十三、老年保健品防骗·套路识别与家属沟通 ⏳

> 核心矛盾：老人被"亲情牌"和"限时优惠"裹挟，子女事后介入常陷入"父母丢面子不愿承认被骗"的困境。核心方法论：**五大套路识别 + 三不原则 + 家属沟通四式 + 退一赔三维权**。参考：南昌市中级人民法院会销骗局普法、北湖区人民政府消费指南、郑州市上街区市场监管局提示、山西吕梁法院预警。

### 53.1 会销五套路识别【南昌市中级人民法院 + czbeihu.gov.cn】

老年保健品"温情会销"骗局五大套路 + 反制动作：

| 套路 | 典型话术 | 反制动作 |
|---|---|---|
| ① 免费礼品诱饵 | "送鸡蛋""免费体检""抽奖""义诊" | "先问医生再决定要不要补，保健品不能替药" |
| ② 假专家义诊 | 白大褂冒充"老教授"，故意吓唬"再不治就晚了" | "请提供执业证编号，我可以查卫健委官网" |
| ③ 亲情牌 | "叔叔阿姨"叫得比亲还亲，天天上门陪聊天/做家务 | 拉女儿/邻居旁观其"关怀"的连续性 |
| ④ 夸大疗效 | "包治百病""根治三高""无效退款" | 引《广告法》禁止绝对化用语 |
| ⑤ 限时逼单 | "今天最后一天""仅剩 2 个名额""买三送三" | "先给我书面报价单，我今晚回家商量" |

**关键识别信号**（老人一有反应立即警觉）：
- "**今天最后一天**" → 制造紧迫感
- "**专家亲自坐镇**" → 假专家套路
- "**买三送三/买六送六**" → 大额预付 + 强制囤货
- "**不能告诉儿女**" → 隔离家属监督
- "**内部专属福利**" → 制造"独家"稀缺

### 53.2 防骗三不原则【南昌市中级人民法院】

老人必须牢记的三不原则（简单好记，方便教老人）：

1. **不贪小利**：不轻信免费礼品/免费体检/限时福利——天下没有免费的午餐
2. **不信神效**：生病就医谨遵医嘱，保健品不能替代药品，"包治百病"必是骗局
3. **不盲消费**：面对会场推销保持理性，大额消费**务必和子女商量**——不冲动下单

**正确选购四要点**（老人在正规渠道购买保健品时用）：
- 先问医生再购买（缺什么补什么，别瞎买）
- 正规渠道才放心（医院药房/正规药店/品牌官方旗舰店）
- 大额消费和家人商量（几千上万一定要先和儿女商量）
- 索要发票留凭证（要发票/购物小票/宣传册，作为维权证据）

### 53.3 家属沟通四式（发现被骗后）【lllsfy.shanxify.gov.cn】

老人被诱骗后的**沟通是最大难点**——直接质问会让老人"丢面子"拒绝承认，错失维权窗口。四式话术：

**式一 · 共情开场**（不指责，先接纳情绪）：
> "妈/爸，我不怪你，能理解你当时想的是给自己身体好一点——他们那些人特别会说话，一般人都会上当，这不怪你。"

**式二 · 拉证据不动手**（先固定证据，不抢产品）：
> "我们先把发票/合同/聊天记录都拍下来存一下——万一以后要用得上，也证明你没撒谎。产品先别扔，就放着。"

**式三 · 引共同外部权威**（不靠子女，靠第三方权威）：
> "我们一起打 12315 问一下，让监管来告诉咱这产品是不是真有问题——如果是真的，咱就依法维权；如果没问题，就当多买了个礼物。"

**式四 · 保护父母"面子"**（把决策权还给老人，但用理性框架）：
> "妈，最后决定权还是你的，我只提建议——要不要去退款，你说了算；但我想陪你一起去一次，帮你把话讲清楚。"

**禁忌话术**（一说就炸，老人立即反抗）：
- "我早说过不要买！" → 老人立即防御
- "你怎么这么傻！" → 老人觉得被羞辱
- "我要告诉爷爷奶奶" → 老人觉得被背叛

### 53.4 维权四步 + 退一赔三【nczy.jxfy.gov.cn】

被骗后维权四步法 + 法律依据：

**四步维权**：
1. **留存证据**：付款记录 + 收据发票 + 宣传海报/视频 + 聊天记录 + 产品实物（**全部证据，一件不留**）
2. **及时沟通**：第一时间告知家人 + 联系商家协商退款退费
3. **投诉举报**：协商无果 → **12315**（市场监管）+ **12345**（政务热线）
4. **司法维权**：涉案金额较大 → **110 报警**（诈骗）或**起诉**（退一赔三）

**法律依据**（引用三条，最有力）：
- 《消费者权益保护法》第 55 条：**经营者欺诈 → 退一赔三**（退全款 + 三倍赔偿）
- 《食品安全法》/《广告法》：**普通食品/保健品不得宣称医疗功效**（"治病""根治"违法）
- 《刑法》：涉案金额较大 → **诈骗罪/虚假广告罪**（追究刑事责任）

### 53.5 三查清单 + 家庭防骗公约

老人自己查证的三查 + 家庭级防骗公约：

**三查清单**：
1. **查资质**：药品看"国药准字"、医疗器械看"注册号/备案号"、保健食品看"蓝帽子"标志（都在国家药监局/市场监管总局官网可查）
2. **查渠道**：正规医院/药店/官方电商；不碰小区讲座/公园/陌生人微信/电话推销
3. **查证据**：主动索取发票/收据/产品包装/说明书/宣传册（维权关键）

**家庭防骗公约**（子女与老人共同约定，贴在冰箱上）：
- 大额（≥ 5000 元）消费**必须**通知子女
- 保健品**只能**在医院药房或官方旗舰店购买
- "限时/最后一批/独家"话术**一律**回家商量
- 每月家庭健康会：**医生 > 保健品销售 > 邻居推荐**（优先级）

**关键洞察**：被骗老人往往**不是"傻"**——是他们被"亲情+权威+限时"三合一话术精准击中。家属的核心不是"教老人变聪明"，而是**建立家庭级的信息屏障**，让骗局在进入老人生活前先被拦截。

## 五十四、留学申请与中介避坑·套路识别与合同谈判 ⏳

> 覆盖本科 / 硕士 / 博士中介申请全链路：签约 → 材料 → 出offer → 落地。
> 来源：新东方前途 / 金吉列 / 启德 / 新航道 / 环球雅思 + 消保委案例 + 知乎留学中介避坑帖 + 12315 举报库

### 54.1 中介八套路识别（先识破再谈判）

| # | 套路话术 | 真相 |
|---|---|---|
| 1 | 「我们出过 X 个常春藤」 | 无独立可查证据，往往是"某学员自己DIY"，中介蹭名 |
| 2 | 「保送 XX 名校」 | 无任何机构能"保送"——只能承诺"申请到 X 所"，且要写进合同 |
| 3 | 「我们老师都是前招生官」 | 招生官不会离职去中介，多是"海外顾问"甚至兼职大学生 |
| 4 | 「这个方案只有我们能做」 | 90% 的方案可复制，跨机构比价看差异 |
| 5 | 「先付定金锁名额」 | 定金 ≠ 意向金，写"意向金"可退，写"定金"受民法典 587 条罚则 |
| 6 | 「这个学校今年扩招了」 | 无官方数据源，中介信息滞后 1-2 年 |
| 7 | 「文书我们模板化了」 | 模板 = 撞车风险，要求"手写 + 3 轮修改" |
| 8 | 「我们内部有捷径」 | 内部捷径 = 造假（伪造文书 / 篡改材料），毁你终身 |

### 54.2 签约五必查（合同是唯一的护身符）

- **查资质**：教育部涉外监管网查"自费出国留学中介资质认定"（编号 CNXXX 开头），无资质一律拒签。
- **查金额**：**服务费必须写清总价**，不接受"另计"、"包不包括申请费"留白；常见 3-8 万 RMB，按国家 / 学校数量阶梯定价。
- **查退费**：**必须写退费计算规则**——① 触发条件（几所 / 何时）② 计算方式（已办理项 × 单价扣减）③ 时限（X 日内到账）④ 手续费上限（一般 ≤ 5%）⑤ 换导师条款。
- **查主体**：合同盖章方必须是"资质持有公司"，不能是"关联公司 / 分公司"——出事后追责主体不同。
- **查管辖**：优先约定"甲方所在地"或"合同签订地"——维权成本天差地别。

### 54.3 材料造假红线（碰一下全毁）

**四类红线绝对不碰**：
- **文书造假**：中介"帮忙写"变成代写 / 抄袭——一旦被查（学校会查重），永久拒学，签证吊销。
- **材料伪造**：语言成绩（托福 / 雅思代考）、推荐信（老师不知情被冒名）、成绩单（改分）。
- **背景编造**：伪造实习 / 竞赛 / 论文署名，学校会做背景核查。
- **身份造假**：伪造身份证 / 学位证 / 户口本——涉嫌刑事犯罪。

**遇到中介暗示"可以做"**：立刻换中介 + 拉黑 + 举报（消保委 + 涉外监管局）。

### 54.4 文书质量四看（拒接模板化）

- **看逻辑**：不是"我热爱 XX 专业"，而是"我做过 X 项目，因此对 XX 有独到理解"——具体行为 → 专业兴趣的因果链。
- **看数字**：具体项目名、公司名、时间、成果数字；模板文书必是"我做过很多项目"这种空话。
- **看个性**：包含 3-5 处只有你能写的细节（如"我的本科老师王教授"、"我在 XX 市 XX 区做的田野调查"）。
- **看修改**：至少 3 轮修改 + 你能说清每次改了什么——1 稿定终 = 模板。

### 54.5 隐性收费陷阱五查

- **语言培训另计**：中介承诺"包出 offer"，但语言培训费另收 1-3 万；签约前问"总花费上限"。
- **加申学校另收费**：签约说"含 5 所学校"，实际按"每加一所 3000 元"。
- **签证费另计**：中介收 2000-5000 元签证服务费，签证官不收这个费用。
- **文书翻译费另计**：说"含翻译"，实际中文材料翻英每页 100 元。
- **境外服务另计**：说"含境外服务"，实际接机、租房、开户另收 3000-8000 元。

**统一话术**：「请把合同里所有可能发生的费用全部列出来，签之前我要看到上限数字，超出上限的部分我不认账。」

### 54.6 退费五步 + 举报四渠道

**退费五步**：
1. **书面交涉**：邮件 + 挂号信双通道，附合同第 X 条 + 已支付凭证 + 明确诉求（金额 + 时限）。
2. **3 天无回应**：拨打中介总部客服 + 记录工单号。
3. **5 天无回应**：12315 平台 / 微信小程序举报。
4. **7 天无回应**：申请消协调解（属地消保委）。
5. **调解失败**：小额诉讼（合同金额 ≤ 5 万可走小额诉讼一审终审）。

**举报四渠道**：
- **12315**：消费者权益（消保委）
- **教育部涉外监管局**：中介资质（无资质直接吊销）
- **当地教育局**：中介在境内经营的属地管理
- **消保委**：民事调解

### 54.7 保送话术识别（十句必假）

中介若说出以下任一句，判定为虚假宣传：

1. 「我们和 XX 大学有内部通道」——大学不会与中介签"通道协议"
2. 「保送 XX 常春藤」——常春藤不接受任何机构"保送"
3. 「这个老师是招生官」——招生官不能兼职中介
4. 「我们能拿到 offer letter 模板给你看」——offer letter 有学生个人信息
5. 「保 offer 保签」——签证官独立决定，无中介能"保"
6. 「我们做过 100% 成功案例」——无独立数据源
7. 「这个学校今年招 500 人」——招生数字每年调，中介无官方数据
8. 「我们和 XX 教授熟」——教授私下接中介 = 违反学术伦理
9. 「你可以先交定金锁 offer」——无任何 offer 可提前锁
10. 「我们不承诺但基本没问题」——"基本没问题"= 无承诺

## 五十五、理财骗局与资金盘·套路识别与家庭防骗 ⏳

> 覆盖 P2P / 资金盘 / 杀猪盘 / 虚拟货币 / 保险返点 / 高息存款 6 类骗局。
> 来源：央行反诈中心 / 国家金融监督管理总局案例库 / 各地经侦通报 / 新华社反诈专栏 + 家庭防骗实操

### 55.1 六类骗局套路识别

| 类 | 特征话术 | 核心陷阱 |
|---|---|---|
| P2P 平台 | 「年化 12-18%」「银行级风控」 | 平台挪用资金跑，投资人血本无归 |
| 资金盘 | 「原始股」「区块链」「内部名额」 | 庞氏骗局，用后头人钱付前头人 |
| 杀猪盘 | 「美女 / 帅哥 + 高收益内幕消息」 | 情感 + 投资双控，先让你赢后让你输 |
| 虚拟货币 | 「比特币 / 以太坊稳赚」 | 无监管机构，平台可随时关停 |
| 保险返点 | 「买 XX 险返 20% 现金」 | 保险返点 = 违法，业务员私自操作 |
| 高息存款 | 「年化 6-10% 稳赚不赔」 | 银行定期最高 4%，超过即诈骗 |

### 55.2 防骗三不原则（家人牢记）

- **不贪**：年收益 > 6% 就要警惕，> 10% 一定是骗局。银行存款最高 3.5%（1年期），任何"稳赚不赔 6%+"都是诈骗。
- **不信神效**：任何"内部消息""内幕""原始股"都指向资金盘。合法金融机构不会用"内幕"这个词。
- **不盲消费**：不认识的机构、听说的产品、朋友推荐但没说清的——一律不碰。

### 55.3 家人被推荐了怎么办（三查清单）

**一查机构**：
- **正规银行 / 券商 / 保险**：国家金融监督管理总局官网可查牌照
- **P2P / 互联网金融**：中国互联网金融协会官网查备案
- **境外平台**：一律视为高风险，境内居民不受保护

**二查产品**：
- 年化 > 6% = 灰色
- 年化 > 10% = 诈骗
- 保本 + 高收益 = 必是骗局（国家金融监督管理总局明文禁止"保本浮动"表述）

**三查合同**：
- 合同主体必须是持牌机构，不是个人 / 咨询公司
- 不接受"投资顾问"、"理财师"个人推荐
- 合同必须写明"投资有风险，本金可能损失"

### 55.4 家人陷入后的三阶段应对

**阶段 1：识别期（发现苗头）**
- 家人说"有人推荐高息产品"→ 立即启动查证
- 家人开始频繁看手机 + 谈"稳赚"→ 警惕杀猪盘
- 家人情绪突然高涨 + 突然有钱请客 → 警惕资金盘早期收益

**阶段 2：劝说期（已投小钱）**
- **不硬顶**：说"这有风险" → 家人防御。改用"我们去看看"。
- **共同查证**：一起去国家金融监督管理总局 / 央行反诈中心查产品资质。
- **给面子**：不指责家人"怎么这么傻"，用"这个我们都不太懂"的姿态共同查。

**阶段 3：追损期（已损失）**
- 停止追加投入（哪怕平台说"再投一次就能回本"）
- 收集全部凭证：合同、转账记录、聊天记录、宣传材料
- 立即报警（经侦大队，不是派出所）
- 全国反诈专线 96110 咨询

### 55.5 追损四步 + 法律依据

**四步**：
1. **报警**：拨打 110 / 96110，属地经侦大队受理。带齐合同 + 转账记录 + 聊天记录 + 身份证。
2. **起诉**：民事诉讼，案由"民间借贷纠纷"或"合同纠纷"，追索本金 + 利息。
3. **举报**：国家金融监督管理总局举报热线 12378，属地金融办举报。
4. **维权群**：受害者群里统一行动（避免被平台分头忽悠）。

**法律依据**：
- 《刑法》：非法吸收公众存款罪（**176 条**）、集资诈骗罪（**192 条**）。（注：142 条为生产、销售假药罪；条号已更正，具体立案标准请以最新司法解释为准。）
- 《民法典》：合同无效（第 153 条），可主张返还
- 《反洗钱法》：大额转账需向银行报备
- 国家金融监督管理总局《资管新规》：禁止"保本保收益"表述

### 55.6 家庭防骗公约（贴墙上）

**四条硬边界**：
1. **单笔 > 5 万**：需配偶 / 子女签字，一人决定无效。
2. **年化 > 6%**：需查证国家金融监督管理总局牌照，查证前不投。
3. **陌生平台 / 熟人介绍产品**：一律拒绝，无例外。
4. **境外投资**：一律拒绝，境内居民不受境外法律保护。

**每季度家庭理财复盘**：
- 家人之间公开账户流水（不含工资 / 房贷隐私部分）
- 每季度核对一次：有无异常大额流出、有无新开户
- 老人账户重点保护：单独设"大额转出通知子女"银行服务

## 五十六、医美口腔消费·隐形正畸种植牙套路识别 ⏳

> 覆盖隐形正畸 / 种植牙 / 美白 / 面诊四大消费场景：报价 → 治疗 → 复诊 → 维权。
> 来源：国家卫健委《医疗美容广告执法指南》 / 中华口腔医学会 / 各地消保委案例 + 知乎医美攻略 + 消费者协会通报

### 56.1 医美口腔五套路识别

| # | 套路 | 话术特征 | 拆解 |
|---|---|---|---|
| 1 | 低价引流 | 「99 元正畸评估」「300 元种植牙一颗」 | 到店后强制加项，实际总价 3-10 万 |
| 2 | 焦虑营销 | 「不种牙三年就废了」「不矫正影响脸型」 | 用医学常识制造恐慌，压缩决策时间 |
| 3 | 伪专家头衔 | 「美国博士」「德国博士」「欧洲认证」 | 境外学历需中留服认证，无认证=虚假 |
| 4 | 隐形正畸套路 | 「隐形便宜还美观」「不用打钉」 | 隐形正畸对复杂病例效果不如固定，且需自律戴牙套 |
| 5 | 种植牙套路 | 「韩国种植体便宜」「德系种植体贵」 | 韩国种植体保修短（3-5 年），德系保修长（10-20 年） |

### 56.2 术前知情权四底线

- **决策权**：所有治疗决策需你本人书面签字，不接受"家属代签"（尤其是老人）。
- **方案书面确认**：所有项目、费用、疗程、材料品牌型号全部写进合同 / 告知书，不接受口头承诺。
- **对公付款**：一律走机构对公账户 + 开发票，不接受私人微信 / 支付宝收款。
- **冷静期**：所有超过 1 万的项目，强制给自己 1-3 天冷静期，不在面诊当天付定金。

### 56.3 隐形正畸三看 + 五陷阱

**三看**：
- **看医生资质**：主治医师 / 副主任医师 / 主任医师三档，隐形正畸复杂病例选副主任医师以上。
- **看方案设计**：正规机构会先做 X 光片 + CT 扫描 + 取模，用数字化软件模拟整个矫正过程；不做设计直接报价=不专业。
- **看品牌授权**：国内主流品牌是隐适美 / 时代天使 / 正雅 / 美奥；要求看品牌授权书。

**五陷阱**：
1. **偷工减料**：只排牙不排颞下颌关节，导致咬合紊乱
2. **偷换品牌**：说隐适美实际用其他品牌（要求验品牌授权书）
3. **隐形费用**：附件粘接费 / 保持器 / 复诊费另收 3000-8000
4. **复诊套路**：每次复诊加收 200-500，一年 12 次=6000-6000
5. **效果承诺**：说"保证效果"，实际效果因人而异

### 56.4 种植牙报价拆单

**种植牙标准构成**（单颗）：
- **种植体**：3000-15000（韩系 3000-5000 / 德系 8000-15000）
- **基台**：1000-3000（可含在种植体价）
- **牙冠**：1500-5000（全瓷 / 金属烤瓷）
- **手术费**：1000-3000
- **影像检查**：300-800（CT / 全景片）
- **麻药 / 缝合**：300-500
- **总计**：正常价 6000-25000 / 颗

**报价拆单话术**：
- 「请把每一项单价列出来，包括种植体、基台、牙冠、手术费、麻药、检查费——签之前我要看到总上限」
- 「这个价格含不含骨粉 / 骨膜？如果需要植骨，骨粉是什么品牌、多少钱？」
- 「保多久？保修范围是什么？种植体断裂 / 牙冠崩瓷 / 基台螺丝松动，哪些免费修？」

### 56.5 医美口腔合同五查

- **查资质**：机构《医疗机构执业许可证》+ 医生《医师执业证书》——卫健委官网可查。
- **查材料品牌型号**：种植体、正畸托槽、美白剂的具体品牌 + 型号 + 批号（可要求现场扫码验真）。
- **查费用上限**：总价包干 or 明码标价，不接受"视情况加价"。
- **查保修**：种植体保修期（韩系 3-5 年 / 德系 10-20 年）、美白效果不满意的补救条款。
- **查管辖**：约定甲方所在地（不是机构所在地，避免异地维权）。

### 56.6 术后维权四步 + 医疗损害鉴定

**四步**：
1. **留证据**：术前照、术中记录、术后照、付款凭证、合同、宣传材料
2. **书面交涉**：要求机构 3 日内书面回复处理方案（含具体金额 / 补救方案）
3. **投诉**：卫健委投诉热线 12320 + 消保委 12315 + 医调委（属地医疗纠纷调解委员会）
4. **诉讼**：小额诉讼一审终审（≤ 5 万），案由"医疗服务合同纠纷"或"医疗损害责任纠纷"

**医疗损害鉴定**（诉讼必备）：
- 委托有资质的司法鉴定机构
- 费用 8000-20000（败诉方承担）
- 判定因果关系 + 过错程度 + 损害后果

### 56.7 美白效果不符五场景

| 场景 | 常见话术 | 应对 |
|---|---|---|
| 冷光美白效果短暂 | 「3 个月保持」 | 要求写进合同，超期免费做第二次 |
| 牙齿敏感 | 「正常现象」 | 3-5 天还敏感就是不良反应，要求补偿 |
| 牙齿变黄 | 「饮食习惯影响」 | 要求复诊免费补做一次 |

| 牙齿变色不均 | 「正常个体差异」 | 要求免费补做 + 部分退款 |

## 五十七、招聘中介与就业陷阱（面试话术与反制）

> **场景定位**：应届生 / 求职者 / 转行 / 跨境派遣 / 猎头 / 劳务派遣全流程。
> **痛点**：招聘季一年比一年卷，中介乱象、试岗免费劳动、简历造假背调、试用期无限坑、"高薪"话术……求职者一旦掉进坑，损失不止时间，还有个人信用信息。
> **本节覆盖**：57.1 招聘八大套路 · 57.2 面试五问反查中介资质 · 57.3 试岗与免费劳动识别 · 57.4 简历造假与背景调查红线 · 57.5 违约金与培训费反制

---

### 57.1 招聘中介八大套路识别

**1.「高薪 + 轻松 + 无经验」** —— 三类话术叠加几乎必假：日薪 500+ / 无需技能 / 包住宿。正规大厂 / 民企都发不起。

**2.「面试即入职 + 当天签合同」** —— 正规企业走 3-4 轮面试 + 审批，一天办妥的多半是黑中介 / 派遣公司，甚至把劳动者当"人头"卖。

**3.「先交培训费 / 服装费 / 押金」** —— 《劳动合同法》第九条：用人单位不得以任何名义扣押劳动者证件或收取财物。**收了就是违法**，报警+人社投诉。

**4.「包就业 / 保 offer」** —— 中介收 8000-30000 服务费承诺"3 个月必入职"，实际让你去陪练 / 陪考 / 刷简历。查中介的**人力资源服务许可证**（人社部官网可查）。

**5.「劳务派遣 + 转外包」** —— 名义上你签派遣公司，实际上被派到目标厂；三个月后目标厂以"编制满"为由解约。你只有 15 天工资可拿，维权成本极高。

**6.「境外高薪工作」** —— 海外建筑工 / 船员 / 酒店服务，中介收 5-15 万。陷阱是护照被扣 + 到目的地才发现合同条款被篡改 + 无法回国。

**7.「实习转正 + 试用期无限延长」** —— 说"试用期 3 个月转正"，结果 3 个月末以"能力不匹配"辞退，你白干 3 个月。《劳动合同法》第二十一条规定试用期内不得随意解除，且同一岗位**只可约定一次试用期**。

**8.「简历美化 + 学历挂靠」** —— 中介推销"简历包装 / 学历代考 / 证书挂靠"服务，涉刑事风险（伪造证件罪 / 提供伪造材料罪）。一旦背调或入职后被发现，直接被解雇 + 影响征信。

---

### 57.2 面试五问反查中介资质

去任何"人力资源公司"面试前，问 5 句：

1. **"你们有《人力资源服务许可证》吗？"** —— 让出示原件，编号在人社厅官网可查。
2. **"营业执照上的经营范围包含招聘 / 劳务派遣吗？"** —— 天眼查 / 企查查直接搜。
3. **"劳动合同是与我直接签，还是与派遣公司签？"** —— 派遣公司签的合同意味着你无正式岗位，随时被退回。
4. **"五险一金是从我入职第一月起交，还是转正后才交？"** —— 合法必须入职次月起交；说"转正才交"是违规。
5. **"试用期具体多长时间、薪酬多少？转正 KPI 写进合同吗？"** —— 口头承诺不算数，必须写进合同或 offer letter。

**红旗信号**：中介不愿出示执照 / 催你"今天交钱明天入职" / 说"合同都是走流程不用你操心" —— 立刻走人。

---

### 57.3 试岗与免费劳动识别

**"试岗 3 天看合不合得来"** —— 免费试岗违法，但极常见于小公司 / 门店 / 培训机构。

**识别话术**：
- "我们不看学历，看能力，来试岗 3 天" —— 你干了 3 天活，"不合适"就让你走，你一分钱拿不到。
- "试岗期间你自由发挥，我们观察你的思路" —— 你在给他们做 PPT / 客户方案 / 代码提交，他们"观察"完说"风格不匹配"。

**反制话术（不撕破脸）**：
- "麻烦试岗期也按日薪结算，我们都可以接受透明合作" —— 让商家自证清白，正规公司不会拒绝。
- "我先做个 1 小时任务展示能力，双方都省事" —— 提出"付费 1 小时能力评估"，把主动权拿回来。

**如果已经干了**：保留工时证明（微信沟通、任务单、日报、Git commit），去当地**劳动仲裁委**申请，可主张工资 + 加付赔偿金。

---

### 57.4 简历造假与背景调查红线

**红线一：学历造假** —— 学信网 / 教育部学历查询全国联网，大公司背调 100% 查。伪造学历一旦被发现 = 解除劳动合同 + 记入行业黑名单。

**红线二：工作履历夸大** —— "我参与过 XX 项目"变成"我主导 XX 项目"是常见美化；背调时会问 HR / 直属领导，一旦被证伪就是欺诈。

**红线三：证书挂靠** —— 一级建造师 / 造价工程师 / 消防工程师证书挂靠是灰产，被查出可能构成合同诈骗罪（金额 5-10 万起追刑责）。

**红线四：社保与合同冲突** —— 你说"我在 A 公司做了 2 年"，社保记录却显示同期在 B 公司。这是背调最容易露馅的地方。

**正确做法**：
- **量化但不夸大**："独立负责"改为"作为 3 人小组组长"；"月销 500 万"改为"参与销售达 500 万"。
- **数字必须有据可查**：每份简历上的数字都能在合同 / 发票 / 邮件里找到出处。
- **背调时如实说明**：主动说明离职原因 / 项目角色，比被问出来强 10 倍。

---

### 57.5 违约金与培训费反制

**核心法律武器**：《劳动合同法》第二十二条 / 第二十三条 / 第二十五条。

**允许约定违约金的只有 2 种情形**：
1. **专项培训服务期**：公司花钱送你出去读 MBA / 培训证书，约定服务期 3 年，未到期跳槽需赔培训费（按比例递减）。
2. **竞业限制**：高管 / 研发 / 销售核心岗，约定离职后**不超过 2 年**（劳动合同法第 24 条上限）内不去竞品。**补偿规则（法释〔2020〕26 号「解释一」第 36 条）**：
   - **协议里约定了补偿数额** → 按约定支付；
   - **没约定** → 劳动者履约后可要求按**离职前 12 个月月均工资的 30%** 按月支付，且**不低于当地最低工资**；
   - **因公司原因 3 个月未支付** → 劳动者可请求**解除**竞业限制约定（解释一第 38 条；是"可请求解除"，**不是自动失效**——此前"不支付则协议失效"表述不准，已更正）。
   - （注：「30%-50%」是部分协议的实际约定区间，**不是法定标准**；法定兜底是 30% 月均工资。）

**其他一切违约金条款都无效**：
- "辞职扣 3 个月工资" → 无效
- "提前离职需赔培训费"（无专项培训） → 无效
- "辞职需在竞业名单 3 家企业就职" → 无效

**反制话术**：
- 面试时问："如果我在试用期想离职，需要提前几天通知？扣多少违约金？" —— 观察对方是否绕开"22 条 / 23 条 / 25 条"。
- 签合同时逐项核对违约金条款，让公司盖骑缝章。
- 入职 1 个月内务必申请"入职 30 天邮件 / 合同 PDF 存档"，为日后仲裁留证。

### 58.1 陪诊服务五档分层

| 档位 | 定位 | 服务内容 | 参考价（一线城市单日） |
|---|---|---|---|
| **基础陪诊** | 挂号陪同 | 排队 / 挂号 / 拿报告 | 100-200 元 |
| **全程陪诊** | 就诊陪同 | 陪同进诊室 + 复述医嘱 + 拍照 | 300-500 元 |
| **深度陪诊** | 疑难杂症 | 有医学背景，可协助看片 / 沟通 | 500-800 元 |
| **跨省转诊** | 异地就医 | 陪住 + 转诊协调 + 家属接待 | 800-1500 元/天 |
| **术后陪护** | 术后康复 | 24 小时看护 + 康复训练 | 300-500 元/天（不含食宿） |

**参考来源**：上海市卫健委《医疗陪诊服务规范（试行）》（2024）· 深圳市卫健委相关指导文件 · 各地卫健委"银发服务"专项。

**红旗信号**：日薪低于 100 元（可能是无资质私人接单）；日薪高于 1500 元（可能捆绑不必要的检查）；不签电子合同（无凭证）。

### 58.2 陪诊员资质三查

**查一：平台资质**
- 是否有卫健委备案 / 行业协会准入（如中国康复医学会 / 中华护理学会认证）
- 是否有《营业执照》+《医疗陪诊服务》经营范围
- 是否购买执业责任险（单笔赔付不低于 20 万）

**查二：陪诊员个体资质**
- 是否有护理证 / 医师证 / 康复师证
- 是否参加过医院陪诊培训计划（三甲医院常有公益培训）
- 是否有 3 年以上的医疗行业从业经验

**查三：服务标准**
- 是否签订正式陪诊服务协议（含服务范围 / 时长 / 收费 / 责任划分）
- 是否有服务过程录音 / 定位留证
- 是否承诺"未达成服务目标全额退款"

**避坑口诀**：先看牌照后看人，先签合同后付钱。

---

### 58.3 老年医疗家属四式沟通

**四式一：共情开场，不说教**

❌ "妈你怎么又不去检查？"（指责）
✅ "妈，我最近忙不过来，想找个专业陪诊员帮您跑一趟，您觉得呢？"（征询）

**四式二：把决策权留给老人，但不放权**

- 让老人自己选陪诊员（在 3 个候选中挑）
- 老人拒绝时不硬来，改为"那我们找位男/女 / 医生/护士 / 年龄相近的"
- 每次陪诊后与陪诊员开 15 分钟复诊会，让老人在场参与总结

**四式三：给老人一个"被需要"的角色**

认知症患者常因失去角色感而抗拒就医。给 TA 一个任务：
- "妈，今天陪诊员来，麻烦您教她怎么跟护士沟通"
- "妈，家里的药您最清楚，麻烦您告诉陪诊员该备哪些"

**四式四：把"孝顺"翻译成"专业"**

老人拒绝时最常说的话："我一个人能行" "麻烦别人不好意思"。

翻译公式：**把"我怕你出事"→"医院流程复杂，有专业陪诊员能省 2 小时"**
- 强调"节省时间"而非"关心健康"
- 强调"专业性"而非"孝顺"
- 强调"其他老人都在用"（社会认同）

---

### 58.4 认知症患者就医五注意

**五注意一：不隐瞒病情**

告诉陪诊员是认知症患者，让 TA 有心理准备，用简单句 / 慢语速 / 具体指令沟通。

**五注意二：不塞太多事**

一次就医不超过 3 个流程节点（挂号 / 检查 / 复诊），复杂检查分 2-3 次。

**五注意三：不改变流程**

认知症患者依赖熟悉的流程路径，临时换陪诊员 / 换诊室会让 TA 崩溃。

**五注意四：家属留一个远程电话**

如果家属不能到场，与陪诊员约定"每 30 分钟微信汇报 1 次"，让老人也知道你在。

**五注意五：不追求"完美康复"**

认知症治疗目标是"生活质量"而非"治愈"，与主治医师沟通这一目标，避免过度医疗。

### 58.5 陪诊 vs 陪护 vs 护工的区别

| 项 | 陪诊员 | 陪护员 | 护工 |
|---|---|---|---|
| **服务场景** | 门诊 + 检查 | 住院期间 | 家庭 / 养老院 |
| **服务时长** | 半天 / 1 天 | 24 小时（住院） | 长期（月 / 年） |
| **核心工作** | 挂号排队 + 陪同 | 生活照护 + 情绪支持 | 生活照护 + 康复训练 |
| **是否需要证** | 陪诊服务证（部分省市要求） | 护理员证 | 养老护理员证 |
| **参考价格** | 300-800 元/天 | 150-300 元/天 | 4000-8000 元/月 |
| **典型人群** | 独居 / 异地老人 | 住院老人 | 失能老人 / 术后康复 |

**核心区别**：**陪诊 = 就医跑腿；陪护 = 住院陪伴；护工 = 长期照护**。三者不能互相替代。

## 五十九、裁员赔偿与劳动仲裁（N+1 谈判与证据留存） ⏳

> **场景定位**：主动离职 / 协商离职 / 单方解除 / 经济性裁员 / 竞业限制纠纷。
> **痛点**：公司"协商离职"话术花招多，员工算不清 N+1，不知道哪些证据该留、哪些话不能说、仲裁时效怎么算。
> **本节覆盖**：59.1 三种离职法律定性 · 59.2 N+1 计算四步走 · 59.3 协商离职"话术识别五坑" · 59.4 证据留存六件套 · 59.5 劳动仲裁五步走

---

### 59.1 三种离职法律定性

| 定性 | 谁发起 | 员工可拿 | 关键法律条款 |
|---|---|---|---|
| **主动辞职** | 员工 | 无赔偿（除非有违法事由可主张"被迫辞职"） | 劳动法 38 条 |
| **协商解除** | 双方 | N（工作年限×月均工资） | 劳动合同法 36 条 |
| **单方解除** | 公司 | N 或 2N（违法解除） | 劳动合同法 40 / 47 / 87 条 |
| **经济性裁员** | 公司 | N | 劳动合同法 41 条 |
| **N+1** | 特殊情况 | N + 1 个月代通知金 | 劳动合同法 40 条（未提前 30 天通知） |

**核心区分**：
- **N** = 工作年限 × 月均工资（12 个月平均）
- **N+1** = N + 1 个月代通知金（公司未提前 30 天书面通知，需多付 1 个月工资）
- **2N** = 违法解除赔偿金（公司无理由 / 无正当程序解除）

**月均工资算法**：包含基本工资 + 绩效奖金 + 提成 + 加班费 + 奖金，按入职到解除前 12 个月算，剔除超过当地社平 3 倍部分。

---

### 59.2 N+1 计算四步走

**第一步：确定工作年限**

- 每满 1 年算 1 个月
- 满 6 个月不满 1 年算 1 年
- 不满 6 个月算 0.5 年

**第二步：计算月均工资**

- 取离职前 12 个月平均（含加班费、奖金、提成）
- 剔除超过当地社平 3 倍的部分（社平 3 倍是上限）
- 若实际工资低于当地最低工资，按最低工资计

**第三步：判断是否适用 N+1**

- 公司**未提前 30 天书面通知** + 单方解除（如"能力不匹配""结构调整"）→ 可主张 N+1
- 主动辞职 / 协商解除 → 只有 N，无 +1

**第四步：判断是否可主张 2N**

- 公司无合法理由单方解除 → 可主张 2N（违法解除）
- 公司程序违法（如未通知工会 / 未书面告知理由）→ 也可主张 2N

**示例**：小李入职 3 年 8 个月，月均工资 20000 元，公司单方面以"业务调整"为由解除，未提前 30 天通知。

- N = 4（3 年 + 8 个月算 1 年）× 20000 = 80000
- +1 = 20000（代通知金）
- **合计 N+1 = 100000 元**
- 若公司解除被认定违法 → 可主张 **2N = 160000 元**

### 59.3 协商离职"话术识别五坑"

**坑一：把"协商"包装成"辞职"**

❌ "你写个辞职申请吧，公司这边就好办了"
⚠️ 陷阱：签了辞职申请，你拿不到 N，只能主张工资至最后工作日。
✅ 正确回应："麻烦出个协商解除协议，写明是双方协商解除"

**坑二：把 N+1 说成 N**

❌ "公司给你 N，这是行业标准"
⚠️ 陷阱：**主动辞职没有经济补偿**；协商解除（由公司提出）应付 N，未提前 30 天通知的再付 +1 代通知金。（此坑的旧版表述把"主动辞职"与"N"错误挂钩，已更正。）
✅ 正确回应："咱们明确一下代通知金的部分，未提前通知应该给 N+1"

**坑三：把"绩效不达标"当合法理由**

❌ "你最近绩效不好，公司决定调整"
⚠️ 陷阱：绩效不达标需要先有书面警告 / 培训 / 调岗，直接解除违法。
✅ 正确回应："咱们对一下 PIP（绩效改进计划）的书面材料"

**坑四：把"结构调整"当合法理由**

❌ "业务调整后你的岗位不存在了"
⚠️ 陷阱：合法调整需满足 3 个条件：确实调整 / 岗位被取消 / 提前 30 天通知工会。
✅ 正确回应："麻烦出示向工会提交的书面调整方案"

**坑五：把"竞业限制"当默认条款**

❌ "你要签竞业协议，2 年内不能去同行"
⚠️ 陷阱：竞业限制**必须按月付补偿**，且仅限高管 / 研发 / 销售核心岗。
✅ 正确回应："咱们约定一下补偿比例，通常 30%-50% 原工资"

### 59.4 证据留存六件套

**第 1 件：劳动合同原件**
- 保存纸质 + 电子 PDF，含骑缝章
- 重点看：岗位、工资、试用期、竞业条款、解除条款

**第 2 件：工资流水 + 社保公积金明细**
- 银行 App 导出 12 个月流水（含工资到账明细）
- 公积金 / 社保网上平台下载缴费记录

**第 3 件：解除通知书面文件**
- 书面通知 / 邮件 / 微信截图 / 短信截图
- **口头通知不算数**，必须要求公司出书面解除函

**第 4 件：绩效评估记录**
- 所有季度 / 年度评估表
- PIP 改进计划文档
- 上级绩效谈话录音 / 邮件

**第 5 件：加班记录 + 考勤**
- 打卡记录 / 加班审批 / 调休记录
- 加班费计算依据

**第 6 件：与 HR / 上级的沟通录音**
- 所有协商对话建议录音（部分地区需双方同意录音）
- 保存原始音频文件（勿剪辑 / 修饰）

**证据保管原则**：
- **双备份**：本地 + 云端（网盘 / 加密邮件）
- **原始性**：保存原始格式，勿修改
- **合法性**：录音需符合当地法律（部分地区需通知对方）

### 59.5 劳动仲裁五步走

**第一步：协商**

与公司 HR / 法务协商，明确诉求（N / N+1 / 2N）+ 支付时间。协商期一般给 15-30 天。

**第二步：投诉**

若协商无果，向当地**人社局劳动保障监察大队**投诉，10 个工作日内受理。适合"未签合同 / 未交社保 / 违法解除"等明显违法情形。

**第三步：申请调解**

向公司所在地的**企业劳动争议调解委员会**或街道调解中心申请调解。调解不收费，成功率高（约 60%）。

**第四步：申请仲裁**

向当地**劳动争议仲裁委员会**提交仲裁申请书，时效为**离职后 1 年内**（注意：不是合同解除后，是离职后）。

**第五步：提起诉讼**

仲裁裁决不服可在收到裁决书 15 日内向法院起诉。

**仲裁费用**：劳动争议仲裁不收费（自 2008 年起）。

**仲裁周期**：简易程序 45 日，普通程序 60 日（含延期）。

**各类型案件的法律依据（明确，可直接引用）**：
- 违法解除 → **2N 赔偿金**（劳动合同法第 87 条：按经济补偿标准的二倍支付）
- 未签书面劳动合同 → **双倍工资**（第 82 条：超过一个月不满一年，每月二倍工资）
- 加班费 → 第 44 条（平时 1.5 倍 / 休息日 2 倍 / 法定节假日 3 倍）
- 竞业补偿 → 法释〔2020〕26 号「解释一」第 36/38 条
> ⚠️ **v1.39.4 修正**：此前此处列有「据人社部数据」的四项支持率百分比（75%/95%/65%/80%）——**无法溯源，人社部不按案件类型公开此类统计**，已删除。**引用胜诉率请以法院/仲裁委公布的官方数据为准，或直接引用上述法条依据**——法条依据比"成功率"更能说服对方。
