# 高情商聊天技能（gaoqing-shang-liaotian）v1.11.1

> 通用版高情商沟通技能 —— **任何 AI 智能体都能用**：Claude / Claude Code / Cursor / WPS AI / WorkBuddy / OpenClaw / 任意支持自定义指令的对话产品。
>
> 融合《非暴力沟通》《关键对话》《蔡康永的说话之道》《人性的弱点》《好好说话》等经典方法论，以及何炅、黄渤、蔡康永、汪涵、贾玲等高情商表达者的实战话术智慧。

**核心原则一句话**：高情商不是讨好、不是油滑、不是会背话术，而是"让对方舒服，也让自己自在"——心里装着别人，把真话用柔软的方式说。

## 🎯 使用方法

### 实战模式（默认）

直接描述场景即可，例如：

- 「帮我回这条消息：对方说……」（信息不足时它会先追问关系、场景、目标三要素）
- 「怎么得体地拒绝同事让我周末帮忙值班」
- 「领导当众否定我的方案，怎么回应」
- 「把这句话说得情商高一点：……」（会附改写对比表：原句 → 优化版 → 差在哪）

### 教练模式（练习）

触发词：**「出练习题」「考考我」「陪我练」「再来一期」**

流程：出题（含低情商直觉版）→ 你先自答 → 对照参考话术与底层公式 → 逐条点评你的答案（触犯哪条雷区 + 闪光点 + 修改版）。支持基于你的关系档案出真实场景题。

**role-play 实练子模式**：触发词 **「陪我练一场」「演他」「对练」**（最长匹配优先）。AI 入戏扮演对方（三档对抗强度：日常 / 进阶 / 地狱），你一句句真实应对；中途喊「提示」可得一句旁白点拨；3~5 回合后自动复盘——逐句点评 + 一句对方视角总结。

### 实时对话模式（Live，现场支援）

触发词：**「实时」「在线等」「正在聊」「聊着呢」**，或贴来对方刚发来的消息并带 **「快帮我回」「他刚发来」**

专为"此刻正在聊天"设计：免追问（按最可能假设直接出话术并标注假设）、解码只给一行结论、输出压缩为「可发话术 + 一行依据」；同会话连续贴消息自动复用上下文。日常场景单遍快检抢速度；**金钱 / 当众 / 亲密冲突 / 职场对抗等高风险场景自动切回标准流程——安全优先于快**。

### 📞 语音通话落地（打电话场景）

打电话前想对练、通话后想复盘？两条立即可用的路径：

| 路径 | 做法 | 载体 |
|------|------|------|
| **A. 语音实练教练** | 把《语音通话接入指南》里的 450 字精简版提示词注入元宝 / 豆包自建智能体 → 发起语音通话，AI 就是你的高情商陪练（对练 / 喊「提示」求援 / 复盘） | 元宝（混元 Voice，支持自建智能体）/ 豆包（SeedRealtime 全双工） |
| **B. 通话后复盘** | 真人通话录音转文字 → 贴给带本技能的 AI → 四维解码逐句复盘 + 对方视角总结 | 完整版 SKILL.md |

实时耳返（通话中实时提示）因 iOS / Android 不开放系统通话音频权限暂不可行，详见指南说明。

**➡️ 完整步骤与提示词见 [voice-call-guide.md](voice-call-guide.md)**

### 输出格式（每次话术交付）

1. 最推荐的一版话术（可直接复制）
2. 1~2 版备选（不同语气）
3. 为什么这样说有效（底层逻辑）
4. 避坑提醒（千万别说的话）
5. 自检记录（如 `✅ 自检：5 遍通过（高风险·金钱+当众）`）
6. 若提供了你的原句：改写对比表

> 实时对话模式下输出压缩为「可发话术 + 一行依据」（见上），以抢时间为先。

## 🔒 铁律（内容红线）

1. **真诚优先**：套路为真心服务，不教 PUA、欺骗、操控。
2. **不违法、不越道德底线**。
3. **守住分寸**：不当众揭短、不传播是非、不逼迫表态。
4. **符合中国社会语境**。
5. **拒绝油腻**：不堆砌烂梗彩虹屁，宁可朴素真诚。

## ❓ FAQ

**Q：我的 AI 不支持读取本地文件，references 还有用吗？**
A：把 `SKILL.md` 全文 + 按需粘贴对应 references 即可。最小可用配置 = SKILL.md + 05-自我检查清单.md。

**Q：关系档案会泄露隐私吗？**
A：协议明文规定只记沟通偏好与边界（说话风格、雷区、常用场景），不记收入、健康、家庭矛盾细节。档案文件在你本地，不上传任何服务器。

**Q：为什么输出前要做 3~5 遍自检？**
A：这是本技能的核心机制——话术不是"说得好听"，而是逐字检查过语气、场合、分寸、逻辑、边界五道关。高风险场景（金钱、当众、亲密冲突）强制 5 遍。
